# Phiếu L3 — Tập {N} (mẫu, lessons T6-8) — chủ dự án duyệt 11/10 (tổng kết Tập 6 câu 1f; dùng thử 3 tập rồi hiệu chuẩn lại)

Chủ dự án xem bản xem G2 **một lần**, chấm cột **Điểm** (1–5, ngang tham chiếu; ngưỡng phát hành ≥ 4 mọi dòng, D-009 d), **rồi** mới đọc hai cột máy. Cột máy chỉ gợi ý, **không thay điểm của chủ dự án** (CHARTER §4 chống Goodhart). Muốn không chấm số → ghi "≥ 4" như Tập 6, nhưng dòng nào máy gợi ý ≤ 3 thì chủ dự án ghi một chữ lý do.

| # | Câu hỏi (`quality-framework.md` §8) | **Điểm** | Số đo máy (điền sẵn ở M5) | Mức gợi ý (bảng dưới) |
|---|---|---|---|---|
| 1 | Thấy mình trong câu chuyện? (Vox) | | M5 nhân vật quay lại ≤ 0:45 · M6 · kiểm mù C2 "câu hỏi tôi mang tới được trả lời" x/6 | |
| 2 | Bối cảnh, người, vấn đề, hành trình, đáp án? (Vox) | | kiểm mù lời đúng x/6 · năm luật nhân vật · trả lời ≥ 3/5 câu hỏi khán giả | |
| 3 | Tắt tiếng, hình vẫn nói ý? (3B1B) | | cổng gốc x/y nhịp ĐẠT (% ) · nhịp hết 2 vòng | |
| 4 | Nhịp: chỗ muốn tua? (WSJ) | | quãng tĩnh > 8 s trên spine · freezedetect s · R07 % · mất chú ý kiểm mù (loại khối ≥ 2/6) | |
| 5 | Giọng tự nhiên, ổn định? | | ASR mất từ khoá · số cảnh sinh lại · LUFS/dBTP · A07 lời trên nhạc dB | |
| 6 | Muốn xem tập tiếp? | | (không có số máy — để trống) | — |

**Bảng quy đổi ghi trước (chỉ gợi ý; hiệu chuẩn lại sau 3 tập có điểm số của chủ dự án):**
- Dòng 3: cổng gốc ≥ 90 % và 0 nhịp hết 2 vòng → 4; 80–90 % hoặc ≤ 2 nhịp hết vòng → 3–4; < 80 % → 3.
- Dòng 4: quãng tĩnh > 8 s = 0 và freezedetect < 60 s và R07 ≥ 90 % → 4; một trong ba trượt → 3–4; hai trượt → 3. (Tập 6: 7 · 206 s · 70 % → 3; chủ dự án chấm ≥ 4 → bảng quy đổi đang khắt khe hơn mắt người, hiệu chuẩn lại.)
- Dòng 1, 2, 5: mọi số máy đạt ngưỡng của nó → 4; một số trượt → 3–4.
- Không bao giờ gợi ý 5 (5 = ngang tham chiếu, chỉ người chấm).
