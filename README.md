# crux-lab

Phòng thí nghiệm quyết định tài chính. Kênh `us-personal-finance`, thể loại data-explainer. Đọc [`CHARTER.md`](CHARTER.md) trước.

- `decisions/`: quyết định của chủ dự án, bắt đầu từ [D-001](decisions/D-001.md).
- `genre-spec/`: spec thể loại [data-explainer](genre-spec/data-explainer.md) và pack kênh (`channel/`).
- [`taste-ledger.md`](taste-ledger.md): sổ gu của chủ dự án.
- `episodes/`: mỗi tập một thư mục.
- `toolkit/`: bộ công cụ v0 chép từ bài D; dùng lại, không phải nền tảng.
- `checks/`: luật kiểm khoá SHA, do Phiên K1 viết. Bên dựng không sửa.

Thứ tự thẩm quyền: hiến chương → `decisions/` → spec thể loại → sổ gu.
